    任务剧情

    与派蒙交谈

    终于，你和派蒙准备启程前往旅途的下一站——至冬…

    挪德卡莱 那夏镇
    直接到达至冬
    折叠
    • 派蒙：转眼已经到至冬了啊，我有种刚刚才离开挪德卡莱的感觉。
    • 派蒙：还记得吗？我们离开之前在那夏镇，朋友们为我们送行…
    • 派蒙：终于要出发去见至冬女皇了，她究竟想干什么，又为什么需要神之心，马上就会有答案。
    • 派蒙：这应该也是你的血亲所说的「旅途的终点」，她/他想要让你见证什么呢…
    • 派蒙：哎，只要还没到至冬，就觉得路还很长很长，吃喝玩乐的时候也没什么负担。
    • 派蒙：但一想到终点就在眼前，这些问题就都会涌进脑袋里，一下子就紧张起来了。
      也是时候了。
      我也会有点忐忑。
    MediaWiki:PlotOptions
    • 派蒙：嗯，不过现在我也想通了，用这样的心态踏上最后一段旅程是不对的！
    • 派蒙：我们对抗过魔龙和海怪，击败过神明的造物，直面过预言与深渊的危机，现在更是连月亮都去过了。
    • 派蒙：还有什么是我们没见过，没经历过的呢？
      有道理，谢谢你帮我打气。
    • 派蒙：不用客气，那就跟紧你的超级好向导派蒙，一鼓作气冲向终点吧，我们出发！
    • ？？？：没有想我的事？
    • 派蒙：呜哇，哥伦比娅？你还是这么神出鬼没…
      你怎么知道我在这里…
      我应该没告诉任何人…
    • 派蒙：别、别看我，这次我可没有出卖你！
    • 努昂诺塔：——！
    • 派蒙：原来是你啊，好吧，那确实瞒不住。
    • 哥伦比娅：朋友们都聚在「旗舰」，想要为你送行。
    • 哥伦比娅：我也邀请了桑多涅愚人众执行官第七席，「木偶」桑多涅。以数理解析事象之人，也是茶会上永不缺席的优雅淑女。<br>诞生于枫丹「奇械公」阿兰·吉约丹手下的她，天生聪慧，精通机械数理。在阿兰去世之后，她带着普隆尼亚来到至冬，加入了「愚人众」。<br>尽管她言辞逆耳，看似冷漠，但在挪德卡莱迎来危机的时候，她却依旧挺身而出，拯救了众人。，可是她好像有事要忙，先回至冬去了。
    • 哥伦比娅：临走之前，还留下了几句难听的话，关于你们的，想听吗？
    • 派蒙：呃，她还是老样子。说说看吧…
    • 哥伦比娅：「他/她们去至冬，十有八九是去给女皇陛下找麻烦，我才不要和这样的人显得很熟络呢。」
    • 哥伦比娅：「也麻烦你转告他/她们，不要理所当然地认为在至冬也能得到愚人众至冬国的组织，于500年前，由冰之女皇于登基后建立。<br>组织的职责涵盖了至冬政务与军事的方方面面。<br>组织中的成员由十一位执行官统辖，秉承冰之女皇的意志，在提瓦特的各处活动。执行官的帮助。」
    • 哥伦比娅：「虽然我们合作的这段时光…还算不错吧，但毕竟立场不同，届时别搞得双方都很为难。」
    • 派蒙：怎么说呢，很像是她会说的话，无论是态度还是道理…好吧，我们会尽量和她保持距离的。
    • 哥伦比娅：不，我觉得她这段话的意思是，想让你们去见她。
      为、为什么？
    • 哥伦比娅：只要不做到「双方都为难」这一步就好了。
